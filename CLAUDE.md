# Web novel workspace

This branch is a writing workspace for web novels (progression fantasy, LitRPG, isekai).

- Novels live in `novels/<novel-name>/`. `novels/_template/` is the blank starting point; never write a story into `_template` itself.
- Hand all story writing (brainstorming, story bibles, outlines, drafting, continuing or rewriting chapters) to the `web-novelist` agent.
- After the `web-novelist` finishes a chapter, offer to run the `novel-editor` agent on it for a second opinion. If the author accepts, pass the editor's "Must fix" notes back to `web-novelist` to revise.
- The author is new to coding. Explain any technical step in plain language.
